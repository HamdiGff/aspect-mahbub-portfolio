## 🚀 Quick Start (Local Development)

```bash
# 1. Navigate to the project directory
cd aspect-mahbub-portfolio

# 2. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploy to Vercel via GitHub (Step-by-Step)

### Step 1: Push to your GitHub Account

```bash
# Initialize git (if not already done)
git init
git add .
git commit -m "feat: Aspect Mahbub elite animated portfolio"

# Create a new repository on github.com (e.g. aspect-mahbub-portfolio)
# Link and push your repository:
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/aspect-mahbub-portfolio.git
git branch -M main
git push -u origin main
```

### Step 2: One-Click Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Import `aspect-mahbub-portfolio` from your GitHub repository list.
4. Leave all build settings at default (Vercel automatically detects Next.js).
5. Click **"Deploy"**.
6. Your portfolio is live with free SSL, automatic global CDN edge caching, and preview environments!
